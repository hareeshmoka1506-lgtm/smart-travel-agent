# TravelAI – AI Travel Planner

An AI-powered travel planning application built with FastAPI, LangGraph, MCP, and Azure OpenAI.

## Features

- AI Travel Itinerary Generation
- Destination Recommendations
- Budget Planning
- Interactive Travel Assistant
- Responsive Modern UI
- Dark Mode Support
- FastAPI Backend
- LangGraph Agent Workflow
- MCP Integration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- FastAPI
- Python

### AI Components
- Azure OpenAI GPT-4o
- LangGraph
- MCP (Model Context Protocol)
